# Grand Line First Sea chart

Grand_Line_First_Sea_Classic_Chart.png is the 2880 × 1536 preview. The original chart's blue ocean grid, gold frame, and warm shallows surround 14 miniature builds rendered with Minecraft Java Edition 1.20.1 block textures. The clouds use the vanilla cloud pattern.

## M-key integration

- The individual 384 × 288 transparent PNGs use the island theme names from first_sea_islands.json. The coordinates are the existing First Sea anchors.
- first_sea_background.png contains the ocean grid and frame. The two transparent cloud sprites are separate.
- The player and heading on the preview are examples. Draw them dynamically in game.
- The chart omits Hollow Islet and the Recommended question-mark badge.
